How to use

1. One-time setup (in your terminal)

  • Put your key in a .env file at the project root: OPENAI_API_KEY=sk-... (optional default model: PDF2LATEX_MODEL=gpt-4o).
  • Choose where results are saved (outside the repo): export PDF2LATEX_OUTPUT_DIR=~/Documents/your-folder, then start with pdf2latex serve. Restart serve after changing it.

2. Add PDFs

  • Upload one with Choose File, or drop PDFs into the sources folder shown above and click Refresh.

3. Convert and track

  1. Set the options (model, dense profile for textbooks, workers).
  2. Click Estimate for a free cost preview (no API calls).
  3. Click Convert and watch live progress. Resume continues a half-done PDF.
  4. When a row shows Done, use its download links (monolith / standalone / needs-review).

Conversions spend real OpenAI credit. The same engine also works from the command line, e.g. pdf2latex convert "file.pdf" --dry-run.
