How to use

0. One-time setup (in your terminal)

  • Put your key in a .env file at the project root: OPENAI_API_KEY=sk-... (optional default model: PDF2LATEX_MODEL=gpt-5).
  • Choose where results are saved (outside the repo): export PDF2LATEX_OUTPUT_DIR=~/Documents/your-folder, then start with pdf2latex serve. Restart serve after changing it.

1. Add PDFs

  • Click Add PDF, or drop PDFs into the sources folder shown above and click Refresh.

2. Convert and track

  1. Pick the model and number of workers. Every page is always converted at full fidelity (math, tables, diagrams) — there is no quality to choose.
  2. Open the ⋯ menu on a row for Estimate cost (a free preview, no API calls) and the other downloads.
  3. Click Convert and watch live progress. Resume continues a half-done PDF.
  4. When a row shows Done, use Compile PDF then Download PDF. Reconvert from scratch (in the ⋯ menu) deletes the converted pages and starts over — it asks for confirmation first.

Conversions spend real OpenAI credit. The same engine also works from the command line, e.g. pdf2latex convert "file.pdf" --dry-run.
